# FastClaw Web UI 登录认证系统设计

## 概述

为 FastClaw Web UI 添加登录认证系统，解决当前管理界面无认证的安全风险。支持多用户、管理员/普通用户两种角色。

## 当前问题

- Web UI 根路由 (`/`) 直接重定向到管理界面
- 无任何认证机制，任何人可访问
- 敏感信息 (API keys、配置) 完全暴露
- 公网部署场景存在严重安全隐患

## 技术方案

### 认证架构

| 层级 | 方案 |
|------|------|
| 认证方式 | Session-based + HttpOnly Cookie |
| 密码存储 | bcrypt 哈希 (cost=12) |
| 用户存储 | SQLite (~/.fastclaw/users.db) |
| 权限模型 | admin / user 两种角色 |
| Session 过期 | 24 小时 |

### 为什么选择 Session-based

1. **简单可靠**: Go 标准库支持，无需额外依赖
2. **安全**: HttpOnly Cookie 防止 XSS 窃取
3. **易管理**: 服务端可即时撤销 Session
4. **与现有架构一致**: 用户数据存储在本地文件系统

## 后端设计


### 用户模型

```go
type User struct {
    ID           string    `json:"id"`
    Username     string    `json:"username"`
    PasswordHash string    `json:"-"`           // bcrypt 哈希，不暴露
    Role         string    `json:"role"`        // "admin" or "user"
    CreatedAt    time.Time `json:"createdAt"`
    LastLoginAt  time.Time `json:"lastLoginAt,omitempty"`
}
```

### 数据库 Schema

```sql
CREATE TABLE IF NOT EXISTS users (
    id TEXT PRIMARY KEY,
    username TEXT UNIQUE NOT NULL,
    password_hash TEXT NOT NULL,
    role TEXT NOT NULL DEFAULT 'user',
    created_at DATETIME NOT NULL,
    last_login_at DATETIME
);

CREATE INDEX idx_users_username ON users(username);
```

在 `fastclaw.json` 中添加:


### API 端点

| 端点 | 方法 | 权限 | 说明 |
|------|------|------|------|
| `/api/auth/login` | POST | 公开 | 用户登录 |
| `/api/auth/logout` | POST | 登录用户 | 用户登出 |
| `/api/auth/me` | GET | 登录用户 | 获取当前用户信息 |
| `/api/auth/password` | PUT | 登录用户 | 修改自己的密码 |
| `/api/users` | GET | admin | 列出所有用户 |
| `/api/users` | POST | admin | 创建新用户 |
| `/api/users/:id` | DELETE | admin | 删除用户 |
| `/api/users/:id/password` | PUT | admin | 重置用户密码 |

### 认证中间件

```go
func AuthMiddleware(next http.HandlerFunc) http.HandlerFunc {
    return func(w http.ResponseWriter, r *http.Request) {
        session := GetSession(r)
        if session == nil {
            http.Error(w, `{"error": "unauthorized"}`, http.StatusUnauthorized)
            return
        }
        next(w, r)
    }
}

func AdminMiddleware(next http.HandlerFunc) http.HandlerFunc {
    return func(w http.ResponseWriter, r *http.Request) {
        session := GetSession(r)
        if session == nil || session.User.Role != "admin" {
            http.Error(w, `{"error": "forbidden"}`, http.StatusForbidden)
            return
        }
        next(w, r)
    }
}
```

### 首次启动流程

```
启动时检查 users 表是否存在用户
    ↓
无用户存在
    ↓
从环境变量 FASTCLAW_ADMIN_PASSWORD 读取密码
    ↓
创建默认管理员账户:
  - username: admin
  - password: <环境变量值> 或 <随机生成的16位密码>
    ↓
如果是随机密码，打印到启动日志:
  "Initial admin password: xxxxxxxx"
```

### 路由保护逻辑

1. 未登录用户访问任何页面 → 重定向到 `/login?redirect=<原路径>`
2. 登录成功 → 跳转回原路径或 `/overview`
3. 已登录用户访问 `/login` → 重定向到 `/overview`

### 前端认证状态管理

```typescript
// lib/auth.ts
export async function getMe(): Promise<User | null> {
  const res = await fetch('/api/auth/me');
  if (!res.ok) return null;
  return res.json();
}

export async function login(username: string, password: string): Promise<boolean> {
  const res = await fetch('/api/auth/login', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ username, password }),
  });
  return res.ok;
}

export async function logout(): Promise<void> {
  await fetch('/api/auth/logout', { method: 'POST' });
}
```

## 安全措施

### 密码安全
- bcrypt 哈希，cost factor = 12
- 最小长度 8 位
- 不记录明文密码

### Session 安全
- HttpOnly Cookie: 防止 JavaScript 读取
- SameSite=Strict: 防止 CSRF
- Secure: 仅 HTTPS 传输 (生产环境)
- Session ID: 32 字节随机值

### 登录保护
- 失败限流: 5 次/分钟/IP
- 错误响应统一: "Invalid username or password"
- 成功后记录 lastLoginAt

### API 保护
- 所有 `/api/*` 端点检查 Session (除 `/api/auth/login`)
- 敏感操作 (用户管理) 需要 admin 角色
- 返回 401 Unauthorized / 403 Forbidden 区分

## 实现优先级

1. **P0 - 核心认证**
   - 用户存储、Session 管理
   - 登录/登出 API
   - 登录页面、路由保护

2. **P1 - 用户管理**
   - 管理员用户列表
   - 创建/删除用户
   - 密码重置

3. **P2 - 增强**
   - 登录失败限流
   - 用户管理 UI
   - 密码修改

## 兼容性

- 现有 API Token 认证保持不变 (用于程序化访问)
- Web UI 使用 Session 认证
- 两者可独立配置、同时启用
